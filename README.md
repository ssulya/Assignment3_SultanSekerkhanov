## Project
Football Hub is a responsive one-page website built for Assignment #3.

### Task 1
The **Players to watch** section uses only custom CSS Grid and mobile-first media queries:
- phone: 1 card per row;
- tablet (600px+): 2 cards per row;
- laptop (992px+): 3 cards per row;
- the card alignment and image size also change at breakpoints.

### Task 2
The rest of the page uses Bootstrap 5.3:
- responsive navbar;
- `container`, `row`, `col-*` and `order-*`;
- cards with responsive columns;
- utility classes;
- accordion;
- modal;
- mobile-only text with `d-lg-none`.

## Run
Open `index.html` in a browser. Internet access is needed for Bootstrap CDN.
